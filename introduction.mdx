## Scope

This framework was built for TerritoryRP. It is not a general-purpose, redistributable product today.

A few resources sit in front of a paid or open-source third-party script instead of replacing it outright — [fw_creator](/api/fw-creator) fronts Murphy's character creator and barber, and [fw_clothing](/api/fw-clothing) fronts Murphy's clothing menu. Any such third-party script — those two, Murphy's housing product, or anything else along those lines — is used explicitly for TerritoryRP, under its own license. It is not part of this framework; these pages only document the calls this framework wraps around it.

If this framework is ever made public, those third-party integrations are the first things that change: each gets replaced with a custom, framework-owned solution instead of wrapping someone else's product.
