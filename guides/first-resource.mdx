Wait until [fw_core](/api/fw-core) is ready, then check in with `RegisterResource(1)`.

The check-in is how your script says "I was written for the current set of calls." Right now that set is number `1`. You do not pick a version, and you do not pass your script's name. If a later update changes the calls so an old script would break, the server window tells you to update yours, instead of failing in the middle of someone's visit. [fw_core](/api/fw-core) explains this in full. The other calls still work if you skip it. Do it anyway.

The server can say `fw_core` has started while it is still creating the player list. If you ask once and stop, you asked too soon. Keep asking for about two minutes.

`source` is the client id of the player who triggered the event. It changes every time they join. `nil` means the export did not find what you asked for.

```lua
CreateThread(function()
    local timeoutAt = GetGameTimer() + 120000
    while not exports.fw_core:IsReady() do
        if GetGameTimer() >= timeoutAt then
            print('[my_resource] fw_core is not ready')
            return
        end
        Wait(100)
    end

    local ok, err = exports.fw_core:RegisterResource(1)
    if not ok then
        print('[my_resource] ' .. tostring(err))
        return
    end
end)

AddEventHandler('fw_core:playerLoaded', function(source, player)
    print(('source %d is account %d'):format(source, player.id))
end)
```

Put `RegisterResource` in your own script. You do not type your script's name. The server already knows who called.

`fw_core:playerLoaded` is a server event. It is not sent to the client. Your script hears it only if it is already running. If the player joined before your script started, ask `GetPlayer` instead.

The folder `resources/[framework]/` is only a category. The resource name is the directory name, such as `fw_core`. `dependencies` in the manifest does not start those resources for you. It only stops yours from starting before them. The `ensure` order in `server.cfg` still matters. The list is on the [API start page](/api).

A full resource, with a manifest, a server file, and a client file, is the [crafting](/guides/crafting) tutorial. That one turns 3 Plant Fiber into 1 Rope.

## A good start looks like this

```
[fw_core][info] ready version=1.1.0 api=1
[fw_admin] ready
[fw_characters][info] ready version=1.0.0
[fw_creator] ready
[fw_clothing] ready. Purchases are not charged yet. Cash is fw_money.
[fw_inventory] ready. 5 items.
```

In the server console, `fw_health` and `fw_characters` print status. A player who types them gets nothing.
