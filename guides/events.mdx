---
title: "Events"
description: "Hear an event on the server, send one to a single client, and copy source before you wait."
---

An event is heard only if your script is already running. If your script starts later, you missed it. Put the listener at the top of the file.

## Which side

| You are | You hear it with | You send it with |
| --- | --- | --- |
| On the server, and the event stays on the server | `AddEventHandler` | `TriggerEvent` |
| On the client, hearing the server | `RegisterNetEvent` | The server used `TriggerClientEvent` |
| On the server, hearing the client | `RegisterNetEvent` | The client used `TriggerServerEvent` |

`fw_core:playerLoaded` is a server event. It is not sent to the client.

```lua
AddEventHandler('fw_core:playerLoaded', function(source, player)
    print(('source %d is account %d'):format(source, player.id))
end)
```

On the server, `source` is the client id of the player who triggered the event. Copy it into a local before any wait. After the wait, `source` is no longer safe, and that player may have left.

```lua
RegisterNetEvent('fw_example:claim', function()
    local playerId = source
    Wait(4000)
    if GetPlayerPing(playerId) < 1 then
        return
    end
end)
```

## One player

Send a client event to one player. The second argument is that player's `source`.

```lua
TriggerClientEvent('fw_inventory:rejected', playerId, reason, token)
```

`TriggerClientEvent(name, -1, ...)` reaches every connected player. Use `-1` only when every connected player has to receive it, and the payload is small and rare. A player across the map does not have to draw a bag someone dropped in Valentine. When only nearby players need it, send to those players, or let a client ask when it gets close.

Leave a one-line comment on any `-1` that says why every player needs it.

What the client sends is untrusted. On the server, check the player, the permission, the inventory, the amount, the distance, and the cooldown before money, items, or rewards change. Those amounts are calculated on the server. A reward can be claimed once.

The crafting tutorial shows one server event that does those checks: [a crafting resource](/guides/crafting).
